# 1960年ローマ典礼暦・日本語版 Google Calendar差分同期ツール

`Google Calendar Differential Sync Tool for the 1960 Roman Liturgical Calendar – Japanese Edition`

このrepositoryは、安全なGoogle Calendar差分同期ツールを開発するための専用repositoryです。現在の初期段階は完全オフラインであり、Google Calendarへ接続せず、Production Calendarへ書き込みません。

Credentials、token、Calendar ID、snapshot、stateはcommitしないでください。

典礼暦の生成元は [Blue-jp/tridentine_calendar](https://github.com/Blue-jp/tridentine_calendar)、配布元は [Blue-jp/tridentine-calendar-ja](https://github.com/Blue-jp/tridentine-calendar-ja) です。
